test_seams:
  - Dashboard summary seam: the inventory route renders Total Inventory, Aging Vehicles, and Aging With Action values sourced from GET /inventory/summary, plus a vehicle list sourced from GET /vehicles.
  - URL-owned discovery state seam: make, model, age range, inventoryStatus, actionStatusId, agingOnly, sort, and page are read from and written to the router URL search params; changing any filter resets page to 1; directly entering a URL restores filters/sort/page.
  - Server-query seam: changing filters/sort/page issues the corresponding GET /vehicles request with server-side query keys (make, model, ageMinDays, ageMaxDays, inventoryStatus, actionStatusId, agingOnly, sort, page, pageSize) and renders exactly the returned page; the table does not re-filter, re-sort, or paginate an already-returned page in the client.
  - Filter-options seam: make and model options come from GET /inventory/filter-options; model options narrow when a make is selected (GET /inventory/filter-options?make=...).
  - Filter-chip seam: each active filter renders a removable chip; removing a chip updates the URL and the request; Clear all removes every filter.
  - Aging/order seam: aging vehicles display a readable AGING indicator that is not color-only, and the list follows the server default ordering inventoryAgeDays DESC (oldest first).
  - Empty-state seam: an unfiltered empty inventory shows "No vehicles in inventory." while a filtered result set with zero matches shows "No vehicles match the current filters."
  - Responsive seam: desktop renders a full table, tablet a compact table with lower-priority fields condensed, and mobile a card/list view prioritizing make/model, inventory age, aging status, and current action; tablet/mobile expose filters through a sheet.
  - Accessibility seam: table layouts use semantic table markup, filter controls have accessible labels, and interactive controls have accessible names.
