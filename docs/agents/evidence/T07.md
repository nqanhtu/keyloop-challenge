## Review

Fresh read-only DeepSeek Codex reviewer sessions reviewed the T07 branch:

- Standards axis (initial `08127f6`): PASS with three findings - F1 (medium, fragile focus restoration that also stranded focus on `<body>` for non-click opens), F2 (low, responsive modality proved only by attributes), F3 (low, filter-sheet targets not measured).
- Repair `ec35cb8`: opener captured in the click handler as state (never read from a ref during render), focus-in and focus-out split into separate effects, and a fallback chain (opener by accessible name -> per-vehicle trigger -> results region -> page heading) so closing always lands focus sensibly. - The geometry assertion caught a genuine responsive defect: the mobile fullscreen detail measured 422x876 inside a 390x844 viewport and the tablet sheet lost its gutters; a `box-sizing: border-box` fix resolved both (mobile 390x844, tablet centred with equal gutters, desktop drawer flush right).

### Verification incident and repair

A first Tester run (on `ec35cb8`) observed 1 failure in 6 full e2e runs: a tablet assertion timed out because the React render is gated on the MSW worker async start, which under heavy host load had not resolved within the old 10 s expectation, leaving a blank document. Classification: verification/environment (same class as INC-001), not a product or seam defect; it did not reproduce in about 490 targeted executions. Test-only repair `ef76f20` added an app-ready signal wait after every navigation plus load-tolerant timeouts (no assertion weakened, no sleeps). Re-verification produced 7/7 green full-suite runs including load, and a 13 s delayed-mount probe proved the wait is load-bearing.
