A bounded test-only repair (`3d3fa3f`, src/test only) closed all five, and a fresh re-review confirmed each CLOSED with a negative fixture and no active false positive:

- `T08-SPEC-01` (medium): design-only sync worker/scheduler not rejected - CLOSED. Scheduler/worker imports (node-cron, cron, node-schedule, croner, bree, node:worker_threads), scheduler registrations, and worker/jobs/sync infrastructure paths are now rejected, and the scope scan covers every non-test file under src/.
- `T08-SPEC-02` (medium): color-only aging missed a vehicle-bound component - CLOSED. The check now triggers on isAging references inside JSX-returning functions regardless of binding style, keeping the delegation exemption.
- `T08-SPEC-03` (low): client re-sort/re-filter detection depended on receiver name - CLOSED. Bindings derived from a returned query page are tracked regardless of local variable name.
- `T08-SPEC-04` (low): URL-owned collection state missed camelCase - CLOSED. Trailing case-insensitive tokens (Page/Filters/Sort/Query/Search) are now matched.
- `T08-SPEC-05` (low): second-store duplication required an inline generic type - CLOSED. Bound-name and query-initializer branches were added.

Recorded latent risks (non-blocking, honest re-review findings):

- The scheduler check is coarse: any setTimeout/setInterval whose argument text matches sync/poll/ingest/backfill/reconcil is rejected, so a future compliant UI-local poll timer could false-positive.
- A root-level jobs/sync/workers directory name is treated as design-only infrastructure, so a future tooling directory with such a name could false-positive.
- Residual false negatives remain (for example `setInterval(refresh, ...)` without a sync-like token, and page bindings from non-list-named query objects); these are conservative gaps, not violations.
- The client-page-recomputation check would over-reach if a binding initialized from any list/page/vehicle/inventory query object were later filtered/sorted; safe on the current tree (0 violations across all scanned files).
- The legacy regex helpers now delegate to the shared AST checks but keep their fallbacks, so deduplication is partial.
